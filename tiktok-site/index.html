AutoClip

A desktop application for Windows and Linux.

AutoClip helps a creator turn long videos and live streams into short vertical clips (9:16) with subtitles, and publish the finished clips to the creator's own TikTok account.

What it does

  • Finds the most engaging moments in a long video or a recorded live stream.
  • Renders vertical clips with subtitles and a crop area chosen by the user.
  • Lets the user pick which clips to publish, for example only the highest-rated ones.
  • Uploads the selected clips to TikTok through the official Content Posting API, only after the user has connected their own TikTok account and only to that account.

How TikTok is used

The app uses Login Kit so that the user can authorize it, and the Content Posting API to upload the user's own videos. It requests the user.info.basic and video.publish scopes. Videos are processed locally on the user's computer; nothing is uploaded to any server other than TikTok. The user can disconnect the account inside the app at any time and can also revoke access in TikTok under Settings and privacy → Security & permissions → Apps and services.
